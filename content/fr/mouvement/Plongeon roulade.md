## Description
Plongeon en avant avec une phase de vol avant de prendre appui sur les mains pour rouler en avant.

## Notes
Peut être assez traumatique pour les poignets et les épaules. Bien maitriser les roulade avant de tenter les plongeons, et privilégier les surfaces molles pour les premières tentatives.
