## Description
Passement où une jambe est passée par-dessus une barre pour la crocheter sous le genou, afin de prendre appui sur la jambe et les deux mains. L'autre jambe passe dans l'espace entre les mains, de manière similaire à un kash.

## Notes
Peut être utilisé comme progression pour apprendre le kash sur barre, en particulier pour les apprenants qui ont l'impression de ne pas pouvoir passer les jambes entre les mains.
